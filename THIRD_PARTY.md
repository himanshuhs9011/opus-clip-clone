# Third-party components

ClipForge bundles or downloads these projects. Each keeps its own license; see the linked pages.

| Component | Used for | Source |
|---|---|---|
| YuNet face detector (ONNX) | finding faces | https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet |
| SFace face recognizer (ONNX) | recognising the same person across cameras | https://github.com/opencv/opencv_zoo/tree/main/models/face_recognition_sface |
| WeSpeaker ResNet34 (VoxCeleb, ONNX) | telling voices apart | https://huggingface.co/Wespeaker/wespeaker-voxceleb-resnet34-LM |
| faster-whisper / Whisper | transcription | https://github.com/SYSTRAN/faster-whisper |
| FFmpeg (gyan.dev build) | video processing (downloaded at install) | https://www.gyan.dev/ffmpeg/builds/ |
| yt-dlp | reading video links | https://github.com/yt-dlp/yt-dlp |
| Ollama + Qwen2.5 | local AI clip picking (optional) | https://ollama.com |
| uv | Python setup | https://github.com/astral-sh/uv |
| Deno | JavaScript runtime used by yt-dlp | https://deno.com |

Only download or clip videos you have the rights to use.
